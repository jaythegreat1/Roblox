# Blade Rift

Sword-fighting PvP game for Roblox, built entirely from code with [Rojo](https://rojo.space).
The full design lives in the Blade Rift master plan doc.

- `src/shared` – config and code used by server and client
- `src/server` – arena, characters, error log
- `src/client` – HUD and input
- `scripts/publish.sh` – build and publish (needs `ROBLOX_API_KEY`)
